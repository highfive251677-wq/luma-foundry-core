# Luma Foundry Premium Design Quality Charter

## Purpose

This charter translates public observations into original design constraints for the remaining Luma Foundry templates. It does not copy any reference brand’s code, assets, trade dress, or claims.

## Current Reference Observations

| Reference | Public pattern observed | Original template implication |
|---|---|---|
| Stripe | The homepage combines a concise revenue-led proposition, layered product demonstration, bento-like modules, contextual proof, and audience-specific routes. | Pair a single conversion thesis with information-dense but calm modular product narratives. Use an original visual language for each brand rather than imitating Stripe’s styling. |
| Anthropic | The homepage uses a restrained warm neutral surface, unusually large typographic hierarchy, a compact navigation system, and mission-first editorial framing. | When appropriate, let typography, spacing, and a single deliberate media moment carry the page; avoid decoration that weakens message clarity. |
| Figma | The homepage foregrounds a sparse, high-contrast opening statement, demonstrative interactive moments, product-specific pathways, and capability-led calls to action. | Make the product interaction or artifact legible at the moment it is introduced, then give each audience a clear pathway rather than repeating generic feature cards. |
| Aesop | The homepage combines an editorial full-bleed product story, understated neutral framing, a deep category rail, and product collections that retain their own descriptive context. | For luxury and commerce concepts, give imagery, material language, and individual product narratives space to create desire before asking for a conversion. |

## Mandatory Quality Gates

| Gate | Requirement for every remaining product |
|---|---|
| Absolute visual individuality | A brand must not reuse the prior template’s layout DNA. The production brief records a different hero composition, page rhythm, section order, card logic, and navigation behavior before implementation. |
| Premium intellectual typography | Every product receives a deliberate display and supporting type pairing, a documented contrast strategy, restrained tracking, and intentionally controlled line lengths and leading. |
| Dynamic color emotion and graphic assets | Every product has a distinct palette and original visual motif. Dark themes are optional, never the default; color, material, editorial art direction, and depth must fit the selected industry. |
| Accessible motion and interaction | Interactive and entrance states use transform and opacity where practical, with refined 200–350 ms cubic-bezier transitions for routine controls. Each product includes visible focus, keyboard-usable controls, readable contrast, and a `prefers-reduced-motion` fallback. |

## Batch 02 Design Separation

Batch 02 will use a warm, paper-toned clinical-editorial system for Stilla Care Systems, in contrast with Batch 01’s five existing AI/Tech visual systems. The five Batch 02 sites will each record their own typography, palette, hero mechanic, conversion sequence, asset treatment, and interaction behavior before code is created.
